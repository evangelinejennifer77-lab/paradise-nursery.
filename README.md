# Paradise Nursery

Paradise Nursery is a simple React plant shop application created for a Coursera project.

## Features
- Landing page with a Get Started button
- Company information page
- Plant product listing grouped by category
- Add plants to the shopping cart
- Increase/decrease item quantities and remove items
- Cart subtotal and total quantity

## Tech stack
- React
- Vite
- Redux Toolkit
- React Redux

## Run locally
1. Install Node.js.
2. Open a terminal in this project folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown in the terminal.
